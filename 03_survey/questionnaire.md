# Charging Bharat: Questionnaire

Online survey (Microsoft Forms) for Tier-2 Vidarbha residents aged 18+. Anonymous: no name, email or phone is asked. The data in this repository is **simulated** to match this questionnaire.

Context line shown before the pricing questions: *"Imagine a good electric scooter with about 100 km real-world range."*

## Screener
| Code | Question | Answers |
| --- | --- | --- |
| S1 | Your age? | Under 18 (end survey) / 18–24 / 25–34 / 35–44 / 45+ |
| S2 | Which city/town do you live in? | Nagpur / Gondia / Bhandara / Chandrapur / Wardha / Other Vidarbha / Outside Vidarbha |
| S3 | Do you currently own a two-wheeler? | Yes, petrol / Yes, electric / No |
| S4 | Do you plan to buy a two-wheeler in the next 24 months? | Yes / Maybe / No |

## Brand funnel (RQ5)
| Code | Question | Answers |
| --- | --- | --- |

The real-survey version lists Indian EV brands; the simulated data uses fictional Brand A–F.
